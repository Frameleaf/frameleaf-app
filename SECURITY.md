# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **security@frameleaf.app**. Do not open a public issue or
pull request for a vulnerability.

Include the affected version or commit, the steps to reproduce, and the impact you found. We will confirm
receipt, keep you updated while we work on a fix, and credit you in the release notes unless you would rather
stay anonymous.

## Supported versions

Security fixes are made on `main` and shipped in the next Frameleaf release. Please update to the latest
release before reporting.
