## Voice-over (clean)

Your own account lives behind your name, top right. The account menu leads to two places: Set up your account, for the basics, and Account Settings, for everything else.

Set up your account opens the first time you sign in, and you can reopen it from the menu. It holds a few things that make Frameleaf yours, in any order. Each card you finish gets a Done mark.

Profile sets your display name and avatar. Appearance picks Dark or Light, which applies when you close the page, and the language Frameleaf uses.

Privacy and notifications covers emails about shared albums, On this day memories, and one switch that stops every email from this server. The mobile app card shows a code your phone scans to open this server.

The card at the top links a Frameleaf account. It is optional, your photos stay on this server, and the Frameleaf Cloud series covers it. Choose Done when you are finished.

Account Settings keeps the rest. Your preferences holds your profile, usage, supporter status, app settings and features. Access and security holds your password, PIN, devices and API keys.

API keys let importers and scripts reach your library without your password. Choose Create API key, name it, and tick only the permissions it needs. The key is shown once, so copy it then. Rotate replaces a key, and the old one stops working at once.

Signed-in devices lists everywhere your account is signed in, with this device marked. Sign out any one of them, or choose Sign out other devices to end every session but this one.

Supporter status is where you enter a personal supporter key. Once it is active, a Supporter badge sits beside your name, and Hide the supporter badge keeps supporting without showing it.

App Settings, marked This device, sets display and video playback for this browser. Notifications, in its own area, chooses which emails you get.

Set it up once, and change it any time.

Next up: How Frameleaf's AI works.

## Production notes

- Interface vs docs: user-settings.md lists everything under one "Your account" group. The current interface splits it: Your profile, Frameleaf account, Account usage statistics and Supporter status sit in "Your preferences"; Password, Locked folder PIN, Sign-in provider, Locked tags & people, Signed-in devices and API keys sit in "Access & security"; email choices sit in "Notifications". The doc does not cover Set up your account, App Settings, Features, Notifications or the Frameleaf account section. Narration follows the interface; flag user-settings.md.
- Frameleaf account is a mention only. Linking depends on Frameleaf Cloud sign-in (CLOUD-03, HOLD), so nothing is linked and no link flow is shown; the card's bullets stay on screen but are not read. With the server unlinked, the Frameleaf account section reads "Your administrator has not linked this server to Frameleaf yet. You can keep signing in at home as usual." Capture Jamie's account so the account menu's "Frameleaf Cloud" row (shown to administrators and on linked servers) stays out of the menu shot.
- Supporter status: the doc says administrators also register the server support key here; the current section refuses a server key ("This is a server key. An administrator activates it under Frameleaf Cloud → Licence."). The section's help text says personal keys "cover your account on any server", while frameleaf-cloud.md says a person's key "is tied to this server and to their account"; the VO avoids both claims. No prices appear in this section and none are narrated; "Support Frameleaf" in the menu is not opened.
- API keys: permissions are listed by their raw names (for example asset.read); the default is one read permission. Choosing a delete permission shows "This key can delete the items covered by the selected permissions." Always blur the key value; the reveal dialog also says "Keep API keys private. Closing this window removes this displayed value."
- Signed-in devices: there is no "sign out everywhere including this device" control; "Sign out other devices" keeps this one signed in. The doc's password option "Sign out my other devices" is a separate switch in the Password dialog and is not shown.
- Theme: the setup page applies Dark or Light on Done; App Settings offers only "Theme selection" (follow the system), and the top bar has its own light/dark button. Set up your account itself is always shown dark.
- Set up your account's progress is stored in this browser; the Frameleaf card counts as done automatically once an account is linked, so the ring ends at 4/5 in this capture.
