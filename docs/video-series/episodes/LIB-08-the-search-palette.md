## Voice-over (clean)

Every search starts in one place, the search palette. Choose Search your library in the top bar, or press slash, or Command K on a Mac and Control K elsewhere.

Before you type, it gives you a head start. Recent searches holds your last few, Saved searches holds the ones you kept, and People, When and Places start a search with one click.

Type naturally. Smart search is the default mode. It looks for what a photo shows, not only its name. Matches appear as you type, and Show results opens the full set.

The mode button changes what your words match. Text in photos finds words inside a picture, like this trail sign. Filename and Full path match how a file is named and where it is stored. Description searches captions, and All text searches all of them at once.

Filters can be typed. Write person, a colon and a name, and it turns into a chip when you press space. Place, tag, type, camera, year, month, after and before work the same way. The question mark lists them all, and a click adds one.

To leave something out, put a minus in front of the filter. Minus person Emma becomes Not Emma, and those photos drop out.

Opened from an album, the palette searches that album first. The scope bar shows the count there and in your entire library, so you can widen the search with one click.

When a search is worth keeping, choose Save search and name it. Then pick one of three. A Smart album updates as new photos match. An Album snapshot makes an ordinary album of what matches now. A Saved search runs the search again whenever you want.

Saved searches sit in the sidebar, under your albums, and in the palette. A smart album needs a search by people, tags, media type, dates or smart search, so a file name search can be a snapshot or a saved search instead.

Press slash to start. Add chips to narrow, a minus to exclude, and choose Save search to keep what you found.

Next up: Filters, bulk actions and Compare.

## Production notes

- Interface vs docs: searching.md describes search types in the older vocabulary ("Contextual", "File name or extension", "Full path or folder", "Optical Character Recognition (OCR)") and does not cover the palette, typed filters, exclusion, recent searches or saving. Every label here is the current interface's: "Search your library", mode menu Smart search / All text / Filename / Description / Text in photos / Full path, "Search syntax", "Recent searches", "Saved searches", "Save search", "Save this collection" with Smart album / Album snapshot / Saved search. Flag searching.md for a palette section.
- The index row says "Recent"; the palette heading is "Recent searches" (up to five). "Recent" is the command palette's heading. Recent searches are kept in memory only and are cleared whenever access changes, so run the three sample searches in the same session just before capture.
- The syntax panel prints "−" (a true minus sign), but the parser accepts the keyboard hyphen "-". Type the hyphen key in beat 7. A typed filter only becomes a chip after a space, and person: and tag: must match one of your own named people or tags; otherwise the text stays plain.
- The syntax panel also lists "-word" (Exclude a word) and "exact phrase" (Phrase). The search sends free text as typed, so these are not demonstrated; only filter exclusion is shown.
- Smart search appears only when the server's smart search is on. Its match count is capped ("1,000+"); the counts in beats 4 to 7 are sample values.
- The Save dialog lists Smart album, Album snapshot, Saved search in that order (the index row lists them in another order). Choices stay disabled until a name is entered. With smart search text, Smart album adds: "A smart album keeps each item that passes the rule's threshold, so it can hold different items than this ranked list." Album snapshot confirms "{n} items will be saved in a new album." with Create album, then "{n} items added." and Open album. Smart albums are covered in depth in AI-09.
- The command palette (">" as the first character) is covered in START-04 and is not shown here.
- Footer key hints for the editor's lower third if needed: "↑↓ move · ⏎ open · ⇥ complete · ⌘⏎ all results · esc close".
