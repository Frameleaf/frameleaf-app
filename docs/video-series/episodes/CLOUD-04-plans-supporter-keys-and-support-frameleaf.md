## Voice-over (clean)

Frameleaf is free to self-host, and nothing on your server is ever locked. Two things are for sale: a Frameleaf Cloud plan and a supporter key. Both live in Settings, under Frameleaf Cloud.

Open Plan. Self-hosting needs no plan. A Frameleaf Cloud plan adds remote access, and if a plan ends, only cloud-connected features pause.

A plan costs $6 a month, or $60 a year, which is two months free. Continue to checkout hands you to the Frameleaf store in a new tab, so payment details never touch your server.

Cloud backup is priced separately by what you store, from $7.99 a month per terabyte, with a one-terabyte minimum.

Once you buy, the server picks the plan up by itself and shows when it renews. Remove from this server takes the plan off this server only; the subscription stays in your Frameleaf account.

[pause]

Next, Licence. A licence is a one-time supporter key. It never expires, adds a supporter badge, and takes 20% off Frameleaf Cloud plans. AI credit is priced the same for everyone.

Server keys begin FL-S, and keys for one person begin FL-I. Each key is checked as you type, before it goes anywhere, so a typo shows straight away.

A server without internet access can still be licensed. Copy its instance ID, download the licence file from your Frameleaf account on another device, then use Choose licence file.

[pause]

Anyone can open Support Frameleaf from the account menu. It shows the plans and the supporter keys: $100 for a server, covering every account on it, or $25 for one person.

Already have a key? Enter it here. A personal key covers your own account. A server key is activated by an administrator.

Once a key is active, a Supporter badge appears next to your name. Hide the supporter badge keeps you supporting without showing it. Your preferences, Supporter status, holds the same card.

[beat]

Every price is in US dollars, and neither a plan nor a key ever locks a photo or a local feature.

Next up: Cloud processing: turn it on.

## Production notes

- Narration tone: Plain and unhurried; no selling. Read prices as spoken amounts: "six dollars", "sixty dollars", "seven ninety-nine", "a hundred dollars", "twenty-five dollars", "twenty percent". Read "FL-S" and "FL-I" letter by letter.
- Prerequisites: `FRAMELEAF_CLOUD_URL` set and the server restarted. Without it every card says "Purchasing isn't available on this server yet." and the Licence page says keys can't be activated here. Taylor is an administrator; the AI credit section of Support Frameleaf appears for administrators only.
- States that need a cloud answer: "Continue to checkout" is enabled only on a linked server (beat 4); the active plan (beat 6) and the activated key with its badge (beats 11–12) need a signed certificate, and no certificate verifies on the integration build until the production signing keys replace the placeholders (frameleaf-cloud `docs/app-integration-as-built.md` §8). Capture those states with a browser-level mock of the server's licence answers, the approach `e2e/src/ui/mock-network/cloud-network.ts` uses for the link. The screens themselves are the shipped build. Never follow "Open the store" or "Continue" into the store; the store and any payment page never appear.
- Sample keys (fictional; they pass only the client-side format check): `FL-SAMP-LEKE-YTAD` for the typo in beat 8 (wrong check symbol), `FL-ITAY-LRKE-YSAX` for the personal key in beats 11–12. Never show a real key.
- Every price is from frameleaf-cloud.md: plan $6 a month or $60 a year, server key $100, personal key $25, 20% off plans for a licensed server, cloud backup from $7.99 a month per TB with a 1 TB minimum, AI credit never discounted. The AI credit presets on Support Frameleaf are on screen only; the wallet is covered in CLOUD-06.
- Doc discrepancy: support-the-project.md says to activate a key under "Account settings → Supporter status", and frameleaf-cloud.md says "Your preferences → Supporter". The shipped label is Settings → Your preferences → "Supporter status"; the VO follows the UI.
- Doc discrepancy: support-the-project.md says a supporter key "gives you access to Frameleaf Cloud, enhanced machine learning features and more". frameleaf-cloud.md and the UI say a key adds a badge and a 20% plan discount, and "unlocks nothing". The VO follows frameleaf-cloud.md and the UI; support-the-project.md needs an update.
- Doc discrepancy: the plan cards list "Up to 3 linked servers", which frameleaf-cloud.md does not state (the account-site prototype README calls the included limits placeholders). It stays on screen as printed and is not spoken.
- Doc discrepancy: frameleaf-cloud.md says a person's key "is tied to this server and to their account", while the UI says personal keys "cover your account on any server". The VO says only that a personal key covers your own account.
- Blur the instance ID in beat 9. "Remove licence key…" and the licence grace and expired banners are left for the written guide.
- Never show the staff console. No GPU, storage or hosting provider appears in this episode.
