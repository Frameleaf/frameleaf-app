## Voice-over (clean)

Choose Getting Started and first-run setup opens with its own welcome. Change the language in the corner if you need to, then choose Continue setup.

The rail shows five chapters: Welcome, Account, Library, Protection and Ready. Progress is saved as you go, so you can come back later.

How you'll sign in offers a Frameleaf account, which works through Frameleaf Cloud, or Local account only. When the Cloud can't be reached, the Frameleaf card says so. Choose Local account only: it's stored on this server, and nothing leaves your network.

Create the admin account is required. Enter your name, email and a password; the strength meter and checklist show what it still needs. Confirm it and continue. The password stays on this server and isn't saved with your setup progress.

[pause]

Where your library lives checks that the storage location from your install is writable, and shows its free space. To change it, change the install. Folder layout decides how originals are filed. Year, Month, file is recommended; Change shows the others.

Processing shows the hardware Frameleaf detected and the model tier. Balanced is recommended; Light is fastest on any processor, and Best is highest quality but about twice as slow. Where processing runs is Local only: nothing leaves your network.

[pause]

Protection has Nightly database backups, on by default: every night at two, fourteen kept. They protect albums, people and edits, so leave it on unless another tool backs up the database.

Privacy has two switches. Check for Frameleaf updates asks GitHub once a day and sends nothing about your library. Map tiles load the map; the tile server sees which areas you view.

Bring everything together shows where Google Photos and iCloud Photos imports live. Nothing starts during setup.

[pause]

You're ready lists every choice. Indexing starts as photos arrive, and you can follow it in Activity. Pick the theme you want after setup, then choose Open Frameleaf. Your new, empty library opens.

Only the admin account and a writable library are required. Every other step has a recommended choice that Use recommended accepts, and Settings can change it later.

- The Storage location field shows the path inside the container (the release Compose file mounts `UPLOAD_LOCATION` at `/data`), not the host folder chosen in START-02. That is expected; the VO says "the storage location from your install".
- Free space is shown in decimal terabytes (`formatTb`): a 4.00 TiB volume reads "4.4 TB". The folder layout example path uses the app's own sample asset (`IMG_4021`, 14 September 2026) and the storage label `admin`.
- Processing hours estimates and the "Re-indexing" line appear only on the existing-library flow (START-08). On a new server Where processing runs has one card, "Local only".
- "every night at two, fourteen kept" matches the on-screen "Every night at 2:00 AM, 14 kept."; the summary row reads "Nightly, kept 14 days".
- Docs vs interface: post-install.mdx still describes the old sequence (register the admin with the "Getting Started" form, then separately update the storage template, then set up server backups). The current build folds the admin account, folder layout (storage template), processing model, nightly database backups, update checks and map tiles into this setup flow. Narration follows the build; flag post-install.mdx for an update. The index row names "Welcome, How you'll sign in, Create the admin account, Where your library lives, Processing, Protection, Privacy, You're ready"; the build also has "Bring everything together" between Privacy and You're ready, covered in beat 10.
