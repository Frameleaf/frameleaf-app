# Frameleaf video series

One hundred and nine short videos (each under 3:00) that together demonstrate every documented Frameleaf feature at least once. The series serves three jobs: marketing videos for the public channel, a "learn the concepts" playlist for operators, and how-to clips that embed in help articles.

| File | Purpose |
| --- | --- |
| `STYLE-GUIDE.md` | Logo intro and outro animation, animation vocabulary, voice rules, episode template, sample library |
| `episodes/<ID>-<slug>.md` | One storyboard per episode, timed to the voice-over |
| `voiceover/<ID>.txt` | The narrator's copy for that episode (the production attachment) |
| `VOICEOVER-MASTER.md` | Every voice-over in watch order, one document for the recording session |
| `manifest.csv` | Generated by the check script: id, title, series, type, target and estimated length |
| `check-episodes.mjs` | Verifies structure, logo beats, length and voice-over parity; writes `manifest.csv` and `VOICEOVER-MASTER.md`; `--write-vo` regenerates `voiceover/` from the episodes first |

Run the check from the repository root:

```bash
node docs/video-series/check-episodes.mjs --write-vo
```

## Source of truth and capture

Scripts describe the current Frameleaf product on the integration branch `master/frameleaf-implementation` (checkout `/Users/adamtaylor/Github/fl-integration`). Documentation paths in the tables below are relative to that checkout. Screen captures must come from a build of that branch; a build of `fork/main` still shows the previous interface.

Frameleaf Cloud episodes show only the client side: the cloud pages inside the Frameleaf app and the customer account site. The staff console never appears.

## Status legend

| Status | Meaning |
| --- | --- |
| READY | Everything shown is available in the current build. Capture and publish. |
| HOLD | Script is complete, but a beat depends on a part of the product the documentation marks planned, unqualified or not yet live (Frameleaf Cloud services, Studio render workers, restoration workers). Capture from the design prototype or mock network with the on-screen label "Preview", and publish only after the dependency ships. |

## Playlists

1. **Meet Frameleaf** (MKT): public, benefit-led, 0:45–1:30.
2. **Start here** (START): install to first backup, in order.
3. **Your library** (LIB): browsing, albums, sharing, search, people, pets, map, memories.
4. **Frameleaf AI** (AI): descriptions, tags, moments, smart albums, Best photos, Ask.
5. **Private by design** (PRIV): Locked, sensitive-content detection, location privacy.
6. **Library Care** (CARE): health, repair, duplicates, imports, preservation.
7. **Editing and Studio** (EDIT).
8. **On your phone** (MOBILE).
9. **Running Frameleaf** (OPS): the settings Command Center, processing, storage, backups, users, access, remote access, migration.
10. **Frameleaf Cloud** (CLOUD): account, plans, cloud processing, backup, remote access.

Recommended watch order for a new operator: START → LIB-01, LIB-02 → AI-01 → OPS-01, OPS-03 → CARE-01 → CLOUD-01. Each How-to episode names the next one in its outro.
