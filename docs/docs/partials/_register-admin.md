The person who sets up the server becomes its administrator. The administrator can add other users. Set the server up soon after installing it, from your home network: setup only works from the home network, and only until the server has an administrator. There is no setup code.

- **In a browser:** open `http://<machine-ip-address>:2283` and follow the **Set up Frameleaf** steps. Link the server to your Frameleaf account, or continue with a local account and create the administrator with a name, email and password.
- **In the Frameleaf app:** on the same Wi-Fi, the app finds the new server and offers **Set up**.

See [Setting up a new server](/administration/system-settings#setting-up-a-new-server) for the details.
