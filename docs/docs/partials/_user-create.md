If you have friends or family members who want to use the application as well, you can create additional accounts for them.

1. Open **Settings → Users** and select **Add a person**.
2. Enter the person's **Name** and **Email**.
3. Optionally set **Space for this person** (**No limit** by default), or set the **Role** to **Administrator**.
4. Under **How they first sign in**, choose **A temporary password**, **Email them a link** (when email is set up on your server), or **Your sign-in provider** (when OAuth sign-in is turned on).
5. Select **Add person**. With **A temporary password**, the password is shown only once: pass it on, and they must change it the first time they sign in.
