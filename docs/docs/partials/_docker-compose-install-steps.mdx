### 1. Download matching release files

Create a new folder for this installation:

```sh
mkdir frameleaf-app
cd frameleaf-app
```

From one [Frameleaf release](https://github.com/Frameleaf/frameleaf-app/releases), download `docker-compose.yml` and `example.env`. Rename `example.env` to `.env`. Also download `hwaccel.ml.yml` or `hwaccel.transcoding.yml` from that release if you intend to use hardware acceleration. Follow its signature and checksum verification instructions.

Existing installations must keep their own `.env`, project name, secrets and storage locations. Do not replace them with defaults during an update.

### 2. Configure storage and credentials

Edit `.env`. This example shows the normal required values; replace the paths and password before starting:

```dotenv
UPLOAD_LOCATION=/srv/frameleaf/library
DB_DATA_LOCATION=/srv/frameleaf/postgres19
FRAMELEAF_VERSION=latest
DB_PASSWORD=YOUR_RANDOM_ALPHANUMERIC_PASSWORD
DB_USERNAME=postgres
DB_DATABASE_NAME=frameleaf
TZ=Etc/UTC
```

- `UPLOAD_LOCATION` holds the live media library and generated files. It is **not a backup**. Create it on storage with enough free space.
- `DB_DATA_LOCATION` must be a new empty directory on a local disk. The PostgreSQL 19 image mounts its parent at `/var/lib/postgresql`; never reuse a directory from another PostgreSQL major version or application.
- Use `FRAMELEAF_VERSION=latest` for the current application images. Advanced deployments can pin a specific compatible release version; preserve the database image supplied in the release Compose file.
- Replace the example database password with a strong random value. Alphanumeric characters avoid Compose interpolation and quoting problems. Keep `.env` private.
- Set `TZ` to your timezone if desired, for example `America/Edmonton`.

See [Environment variables](/install/environment-variables) for advanced options. A manually configured external database must meet the [PostgreSQL requirements](/administration/postgres-standalone).

### 3. Start Frameleaf

From the directory containing `docker-compose.yml` and `.env`:

```sh
docker compose pull
docker compose up -d
```

The release defines the container names `frameleaf_server`, `frameleaf_machine_learning` and `frameleaf_postgres`. Open `http://YOUR-SERVER:2283` when the application is healthy.
