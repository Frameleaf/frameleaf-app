# Frameleaf apps

The Frameleaf server includes a web application that works in your desktop or phone browser. Official app pages show current iOS and Android availability; a server installation does not imply that a signed native app is available for your platform.

## Get the app

Use the official [Frameleaf website](https://frameleaf.app) or your server's **Mobile applications** page. Administrators can configure signed app download and store links through the [app release settings](/install/environment-variables#app-releases). If the page says no signed release is available, use the web application until one is provided.

Manager's **Connect your phone** screen also links to the official app pages. Use apps intended for Frameleaf and supported by your server release.

## Connect your library

1. Open the photo application's address in the phone's browser first and confirm that you can sign in.
2. Enter that server address in the app. This is the photo application's address, normally port `2283` on your home network; the Manager address on `9443` is for administration.
3. Sign in with your photo account and follow the app's permissions and catalog setup prompts.
4. Keep the app open during initial setup. Reopen it if the operating system pauses it. Manager shows library verification and phone catalog progress where supported.

Catalog setup prepares browsing data and previews; it does not download every original file. Follow the controls in your installed app for downloads and backup.

## Backup and remote access

Read [Phone backup](/features/mobile-backup) before enabling uploads, and [Remote access](/guides/remote-access) before connecting away from home. Verify a few uploaded originals in the web app before relying on automatic backup or removing files from the phone.
