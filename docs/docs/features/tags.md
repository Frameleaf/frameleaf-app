# Tags

Frameleaf supports hierarchical tags, with the ability to read existing tags from the XMP `TagsList` field and IPTC `Keywords` field. Any changes to tags made through Frameleaf are also written back to a [sidecar](/features/xmp-sidecars) file. You can re-run the metadata extraction jobs for all assets to import your existing tags.

## Enable tags feature

1. Open **Settings** from the sidebar and go to **Your preferences**.
2. In **Library features**, turn on **Enable tags**.
3. To keep a link to the view in the sidebar, also turn on **Show Tags in the sidebar**.

## Creating tags

Tags can be created and added to a photo or a video from the tags area of the info panel:

1. Open the photo or video and show its information panel.
2. In the tags area, choose to add a tag.
3. Find and select an existing tag, or type a new tag to create it.

## Viewing tags

You can navigate to the **Tags** view from the sidebar or by clicking on the tag in the info panel. The view lists your tags as a tree and shows the photos and videos for the tag you pick.
