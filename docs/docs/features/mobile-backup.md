# Phone backup

Use the [official Frameleaf app](/features/mobile-app) available for your platform, or upload from your phone's browser. Backup controls and background behavior depend on the installed app and operating system; follow the options shown by that release.

## Start with a small selection

1. Confirm that the phone can reach your photo server and sign in.
2. Grant the photo access you intend the app to have. If access is limited to selected photos, other files cannot be backed up.
3. Choose the photos or albums to upload and review any network, battery or background options offered by the app.
4. Keep the app open for the first upload. Verify the originals in Frameleaf's web application and download a sample before trusting a larger backup.

Uploads of identical content to the same account can be recognized as duplicates. A copy on the server is still only one backup location: protect the server with [database and media backups](/administration/backup-and-restore).

## When uploads stop

Check the app's status, available server and phone storage, network reachability, permissions and the operating system's background restrictions. Phone operating systems decide when background work may run. Reopen the app to resume the workflow offered by your release.

Browser uploads require the tab to remain open. Closing or reloading it stops pending uploads; selecting the same files again skips items already uploaded. See [Uploads and downloads](/features/uploads-and-downloads).

## Before removing phone originals

Confirm the files are present and downloadable from Frameleaf and that the server has a separate recoverable backup. A phone's photo library may synchronize deletion to another service and to other devices. Review that service's behavior before deleting or using any device cleanup feature. Keeping only the server copy leaves the collection exposed to server or disk loss.
