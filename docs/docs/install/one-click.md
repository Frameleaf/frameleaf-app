# One-Click [Cloud Service]

Frameleaf is not offered as a one-click app by any cloud marketplace yet. The marketplace apps that exist install other software, not Frameleaf.

To run Frameleaf on a cloud server, create a Linux virtual machine with Docker and follow the [Docker Compose installation](/install/docker-compose), using the files from a [Frameleaf release](https://github.com/Frameleaf/frameleaf-app/releases).
