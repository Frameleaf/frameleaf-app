## Upload a small test library

Use **Upload** to choose files or a folder. Leave the tab open until it finishes. Confirm that you can open a photo, play a video and download an original. See [Uploads and downloads](/features/uploads-and-downloads).

## Choose processing settings

Open **Settings** from the sidebar. The Command Center includes **Compute & jobs**, where you can review processing destinations and jobs. Start with local processing and enable only the features you want. Search, faces, text recognition and descriptions need their models and background jobs before results appear.

Review [machine-learning settings](/administration/system-settings), [workers and endpoints](/administration/workers-and-endpoints) and [image enrichment](/features/image-enrichment). Try a few representative items before backfilling the whole library.

## Set up accounts and privacy

Create separate accounts for household members in [User management](/administration/user-management). Use [albums and sharing](/features/sharing) or [partner sharing](/features/partner-sharing) deliberately. Set your [Locked PIN and rules](/features/locked) before putting private items into shared collections.

## Protect the library

Set up [database and media backups](/administration/backup-and-restore), export Manager's recovery configuration if you use it, and test a recovery copy. Use [Library Care](/features/library-care) to scan for missing or damaged originals.

Storage templates are optional. Read [Storage templates](/administration/storage-template) before enabling or changing one, because applying a template can move files within managed storage.

## Add optional features

- [External libraries](/features/libraries) for folders you already manage.
- [Google Photos import](/features/google-photos-import) or [iCloud Photos import](/guides/icloud-photos-sync).
- [Hardware video transcoding](/features/hardware-transcoding) and [machine-learning acceleration](/features/ml-hardware-acceleration).
- [Remote access](/guides/remote-access) with a trusted HTTPS address.
- [Frameleaf apps](/features/mobile-app) when available for your platform.
