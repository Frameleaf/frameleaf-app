# Server Stats

Server statistics show the number of photos and videos and the storage they use, for the whole server or for one account.

:::info External library
External libraries are not included in the storage quota due to custom mount points.
:::

- **Settings → Library analytics** shows growth, storage, cameras, formats and processing. Choose **All accounts & libraries** or one account or library as the scope. Everything on this page is computed and kept on the server.
- **Settings → Users** lists each account; open one to see its usage alongside its quota (or unlimited), or choose **View analytics** for that account.
