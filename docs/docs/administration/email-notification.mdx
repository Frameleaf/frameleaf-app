# Email Notifications

Frameleaf supports the option to send notifications via Email for the following events:

- Creating a new user
- Notifying a user when they get added to a shared album
- Informing other users about the addition of new assets to a shared album

## SMTP settings

You can access the settings panel from the web at `Administration -> Settings -> Notification settings`.

Under Email, enter the required details to connect with an SMTP server.

You can use [this guide](/guides/smtp-gmail) to use Gmail's SMTP server.

You can use [this guide](/guides/smtp-microsoft365) to use Microsoft's SMTP server.

## Links in emails

Emails link back to your server (the album, or the sign-in page for a new account) using the first address the server knows:

1. The external domain in `Administration -> Settings -> Server`.
2. For a server linked to Frameleaf Cloud, the public URL Frameleaf Cloud publishes for it.

When the server has neither, emails are sent without a link and ask the recipient to open Frameleaf on their server instead. Set an external domain if you want links in emails. Without either address, a `{baseUrl}` tag in a custom template is left as written, so set an external domain before using it.

## User's notifications settings

Users can manage their email notification settings from their account settings page on the web. They can choose to turn email notifications on or off for the following events:

- **Enable**: turns all email notifications on or off.
- **Album added**: an email when they are added to a shared album.
- **Album updated**: an email when a shared album has new assets.

Select **Save** after changing these options.

## Notification templates

You can override the default notification text with custom templates in HTML format. You can use tags to show dynamic tags in your templates. An empty template uses the default email. Each template has a **Preview** button.

| Template               | Available tags                                                             |
| ---------------------- | -------------------------------------------------------------------------- |
| Welcome email template | `{username}`, `{password}`, `{displayName}`, `{baseUrl}`                   |
| Invite album template  | `{senderName}`, `{recipientName}`, `{albumId}`, `{albumName}`, `{baseUrl}` |
| Update album template  | `{recipientName}`, `{albumId}`, `{albumName}`, `{baseUrl}`                 |
