# Welcome to Frameleaf

:::warning Release availability

The Manager-based release described in this handbook has not been published yet. The currently published `:latest` application images belong to the preceding release. To install that release, use its supplied Compose file and matching instructions. Do not combine the PostgreSQL 19 storage layout below with an older application image or database.

:::

Frameleaf keeps your photos and videos on your own server. Browse your library, organize albums, search by people, places or content, edit without replacing originals, and share the items you choose.

## Set up your server

Start with [Frameleaf Manager](/install/manager). It guides you through a new library, importing a supported existing installation, or restoring a Manager backup. You need a Linux Docker host, persistent storage and a verified release. Check the [requirements](/install/requirements) first.

If you already administer containers, follow [Manual Docker Compose](/install/docker-compose) and the [environment variable reference](/install/environment-variables). The photo application normally opens at `http://YOUR-SERVER:2283`; Manager uses its separate HTTPS address on port `9443`.

## Open your library

1. Select **Upload** and add a few photos or a folder. Keep the tab open until the upload finishes.
2. Open a photo to see its details, favorite it, or add it to an album.
3. Open **Settings** in the sidebar. Review processing destinations before enabling optional remote features. Local machine learning can prepare search, faces, text and descriptions; initial processing takes time.
4. Check **Compute & jobs** for processing progress and **Library Care** for missing or damaged files.

See [Uploads and downloads](/features/uploads-and-downloads), [Searching](/features/searching), and [Sharing](/features/sharing) for the next steps.

## Bring in the rest of your library

- [External libraries](/features/libraries) index a folder you already manage.
- [Google Photos import](/features/google-photos-import) imports a downloaded Takeout export.
- [iCloud Photos](/guides/icloud-photos-sync) connects a configured iCloud importer.
- The [command-line client](/features/command-line-interface) uploads larger local archives.
- [Frameleaf apps](/features/mobile-app) explains app availability and connecting a phone.

## Protect your collection

Set up [database and media backups](/administration/backup-and-restore) before adding your only copy of anything. A database backup does not contain your photos or videos. Keep a separate recovery copy and check that you can restore it.

[Post-installation setup](/install/post-install) covers accounts, sharing, processing and storage. For help, start with the [FAQ](/FAQ) or [troubleshooting](/overview/help).
