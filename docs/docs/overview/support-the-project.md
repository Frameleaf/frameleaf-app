# Support Frameleaf

## Report issues

By far the easiest way to help make Frameleaf better is to use it and report issues and bugs. Found a bug? [Open an issue on GitHub][github-issue].

## Translations

Help translate Frameleaf by opening a pull request with changes to the language files in the [Frameleaf repository][github-repo]. For more information, see the [Translations](/developer/translations) section.

## Development

If you are a programmer or developer, take a look at the [technology stack](/developer/architecture.mdx) and consider fixing bugs or building new features. For information about how to contribute as a developer, see the [Developer](/developer/architecture.mdx) section.

## Supporter key

Frameleaf is made by a small team and funded by the people who use it. You can support Frameleaf with a supporter key for one account or for your whole server.

Get a key from **Support Frameleaf** in the account menu. A **Server** key covers everyone on your server, an **Individual** key your own account. If you already have a key, activate it under **Settings → Your preferences → Support Frameleaf**.
