# Frameleaf Connect for Zapier

Connection foundation only. Actions, searches, files and triggers are not available yet. Do not publish or use this package in production.

This qualification connection requests library:read only. Select the exact owned albums in Frameleaf consent; whole-library reading is an explicit choice. No originals, people or writes are requested.

Zapier must reach a public HTTPS Library address. Customer-provided HTTPS needs no Frameleaf Cloud plan; Frameleaf relay needs an eligible plan. Zapier subscriptions and usage limits are separate. LAN-only access is unsupported.

In Zapier, obtain the exact callback for this private application. A Frameleaf administrator registers that exact callback in Connect setup and supplies the non-secret client ID. Enter the canonical server origin and client ID, then complete browser consent. Never paste tokens into a Zap field.

Hosted OAuth and concurrent refresh must pass before adding features. Verify simultaneous Zaps sharing one connection produce one safe rotation, persist the entire token set, preserve credentials after an uncertain response, and revoke correctly. This source does not prove those platform behaviors.
