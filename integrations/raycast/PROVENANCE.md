# Licensing and provenance

The Raycast extension and its tests were independently written against the public Frameleaf Connect HTTP contract ([protocol 1](../../docs/developer/connect-api.md)) and the Raycast API. No Frameleaf Library SDK or Immich implementation code is incorporated. The extension is licensed MIT, as the Raycast Store requires. The icon is Frameleaf's own app icon.
