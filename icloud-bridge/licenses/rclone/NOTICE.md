# Rclone license provenance

`COPYING` is an unmodified copy of the Rclone v1.75.1 module's original
MIT copyright and permission notice. Upstream names this file `COPYING`,
not `LICENSE`.

- Module: `github.com/rclone/rclone` v1.75.1
- Peeled release commit: `687d264b689b8c49a67e2e52a8a5e0caa01c04ce`
- Original: https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/COPYING
- Imported package: `backend/iclouddrive/api`

The runtime Docker image retains both files under
`/usr/share/licenses/icloud-bridge/rclone/` alongside the compiled bridge.
The bridge uses the pinned module without a source fork; its raw CloudKit
adapter is documented in `api.md`.
