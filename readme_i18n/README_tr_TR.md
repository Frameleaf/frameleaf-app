Web demo adresi: https://demo.immich.app. Mobil uygulama için `Server Endpoint URL` olarak `https://demo.immich.app` adresini kullanabilirsiniz.

```bash title="Demo Bilgileri"

email: demo@immich.app
password: demo
```
