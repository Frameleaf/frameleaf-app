Construction
These are actual SVG vector files, recreated from the approved dark concept.
The frame and leaf are redrawn with simplified cubic Bezier curves. The rounded wordmark is reconstructed with clean geometric paths in the style of
the reference. The handwritten signoff is traced from the reference.
Supporting text is converted to outlines, so the artwork has no runtime font
dependency. No font files, embedded bitmaps, scripts, or external resources are
included. All gradients and soft background accents are native SVG elements.
The recreation is not a pixel-exact conversion of the generated PNG; raster
texture and glow have been replaced with scalable vector gradients.

Usage
Use frameleaf-logo-dark.svg on a dark background; it is intentionally transparent
and its 'Frame' lettering is white. Use frameleaf-symbol.svg for compact branding
or a browser favicon. The app tile has rounded transparent corners; platform
app-store submissions may require a platform-specific solid square export.
Each asset includes an SVG viewBox and scales without a fixed pixel resolution.
Artwork is organized into labeled groups. Individual vector nodes, fills, and
gradient stops can be edited in a vector editor; outlined letters are shapes,
not live editable text. No font installation is required.
