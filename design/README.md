# Design references

Start with the [design instructions](AGENTS.md) and [original SVG brand kit](frameleaf/brand-kit/README.txt). The interactive prototype, its references and animations live in the private `Frameleaf/frameleaf-prototype` repository; local copies under `frameleaf/template/`, `frameleaf-manager/`, `frameleaf/references/` and `frameleaf/animations/` are excluded from Git and published artifacts. Use the authorized private design requirements for written decisions.

Use Frameleaf's supplied artwork for new identity work; do not rename or replace compatibility-sensitive application identifiers through a global asset rename.
